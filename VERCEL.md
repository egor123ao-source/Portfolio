# Публикация на Vercel

Проект готов к размещению как статический многостраничный сайт. Здесь нет базы данных, серверного приложения, API-ключей и обязательных платных сервисов. Node.js нужен только для сборки.

## Вариант 1 — GitHub и панель Vercel

1. Распакуйте `ggh-portfolio-vercel.zip` в отдельную папку. Файлы `package.json` и `vercel.json` должны лежать в её корне.
2. Создайте репозиторий GitHub и загрузите в него содержимое распакованной папки. Папку `dist` добавлять не нужно: Vercel создаст её при сборке.
3. В Vercel выберите **Add New → Project**, подключите GitHub и импортируйте репозиторий.
4. Проверьте настройки в таблице ниже. Если файлы находятся в корне репозитория, оставьте Root Directory пустым / `.`. Если импортируется вся рабочая папка с вложенным проектом, выберите `ggh-portfolio`.
5. Нажмите **Deploy** и дождитесь статуса **Ready**. Vercel покажет адрес сайта.

ZIP — упаковка исходников: для этого способа сначала распакуйте его и загрузите файлы в GitHub.

| Настройка | Значение |
| --- | --- |
| Framework Preset | Other |
| Root Directory | `.` для распакованного архива; `ggh-portfolio` для всей рабочей папки |
| Node.js Version | 24.x |
| Install Command | `npm ci --ignore-scripts` |
| Build Command | `npm run build && npm run check` |
| Output Directory | `dist` |

Команды и каталог результата зафиксированы в `vercel.json`, версия Node.js — в `package.json`.

## Вариант 2 — терминал, без GitHub

Установите Node.js 24.x. Откройте терминал в распакованной папке рядом с `vercel.json`:

```sh
npm ci --ignore-scripts
npm run build
npm run check
npx vercel@latest
```

Войдите в свой Vercel-аккаунт по подсказке CLI. Для каталога проекта выберите `.`. Можно привязать существующий проект или создать новый; готовые параметры сборки уже заданы в файлах.

Первая команда `npx vercel@latest` создаёт тестовое размещение. Когда всё устраивает:

```sh
npx vercel@latest --prod
```

Чтобы заменить прежнее портфолио, при привязке выберите существующий проект `exactcopyeleshportfolio`, если он доступен в вашем аккаунте. Выбор существующего проекта и команда `--prod` обновят его основную публикацию. Если хотите отдельный адрес, создайте новый проект.

## Домен и поисковики

Для обычного адреса Vercel переменные вручную не нужны, если включён доступ к системным переменным окружения. Сборка использует `VERCEL_PROJECT_PRODUCTION_URL`, а при его отсутствии — `VERCEL_URL`.

Для собственного домена:

1. Добавьте домен в **Settings → Domains** и выполните показанные Vercel DNS-настройки.
2. Добавьте в **Settings → Environment Variables** переменную `SITE_URL` со значением вида `https://your-domain.kz`. Для единых canonical-ссылок задайте её и для Production, и для Preview.
3. Запустите **Redeploy** после изменения домена или переменной.

`SITE_URL` принимает только `http://` или `https://`, домен и необязательный завершающий `/`. Путь вроде `/portfolio`, query-параметры и фрагменты не допускаются. Предпросмотры и localhost имеют `noindex`; основная публикация содержит индексируемые страницы, sitemap и robots.txt. Страница 404 всегда имеет `noindex`.

Если автоматический адрес недоступен, включите **Enable access to System Environment Variables** в настройках окружения Vercel либо явно задайте `SITE_URL`.

## После публикации

- Откройте `/works/`, `/services/`, `/about/`, `/contact/` напрямую и обновите страницу.
- Проверьте `/works/esports-pulse/` и просмотр изображений.
- Откройте произвольный несуществующий адрес: должна появиться собственная страница 404.
- Проверьте `/sitemap.xml`: адреса должны содержать ваш основной домен.
- Соберите пробное сообщение с собственной суммой: текст должен появиться до перехода в Telegram или WhatsApp.

Форма не отправляет сообщение автоматически. Посетитель проверяет черновик и сам отправляет его в мессенджере. Для этого не нужен backend или сторонний сервис форм.

Файл `.openai/hosting.json` в исходной рабочей папке относится к прежнему размещению и не нужен на Vercel. В подготовленный ZIP он не включён. `server.mjs` используется только для локального просмотра и не запускается на хостинге.

Документация: [настройки vercel.json](https://vercel.com/docs/project-configuration/vercel-json), [системные переменные](https://vercel.com/docs/environment-variables/system-environment-variables), [статическая 404](https://vercel.com/kb/guide/custom-404-page).
