# Егор / ggh_then

Многостраничное портфолио: главная, работы, услуги, об авторе, контакт, четыре страницы проектов и 404.

## Запуск

Нужен Node.js 24.x. Зависимостей для сайта нет.

```sh
npm run dev
```

Локальный адрес: http://localhost:4173. Для проверки сборки:

```sh
npm run build
npm run check
```

`dist/` — готовый статический сайт. Пошаговая публикация: [VERCEL.md](VERCEL.md).

## Vercel

Настройки уже сохранены в `vercel.json`: Framework Preset — **Other**, сборка — `npm run build && npm run check`, результат — `dist`, Node.js — **24.x**. Отдельные HTML-страницы открываются по адресам `/works/`, `/services/` и т. д. Неизвестные адреса получают страницу 404.

Для GitHub Import загрузите содержимое этой папки в корень репозитория. Если загружаете всю рабочую папку `portfolio site`, укажите **Root Directory: `ggh-portfolio`**.

Либо откройте терминал в этой папке и выполните:

```sh
npx vercel@latest
```

После проверки тестового адреса опубликуйте основную версию:

```sh
npx vercel@latest --prod
```

Домен для canonical, Open Graph и sitemap выбирается так: `SITE_URL` → `VERCEL_PROJECT_PRODUCTION_URL` → `VERCEL_URL` → `http://localhost:4173`. Для собственного домена задайте `SITE_URL` в настройках Vercel, например `https://your-domain.kz`, и запустите новую сборку. Переменная должна содержать полный адрес без пути. Файлы `.env` автоматически не читаются сборщиком: локально переменные задаются в терминале.

Тестовые Vercel Preview и локальная сборка закрыты от индексации; основная публикация с публичным доменом разрешена. Сборка не зависит от аккаунта или файлов Sites.

## Где редактировать

- `src/data.mjs` — проекты, контакты, услуги, цены и ответы об условиях.
- `src/config.mjs` — адрес сайта и правила индексации для разных окружений.
- `build.mjs` — общие шаблоны и тексты страниц.
- `public/styles.css` — визуальная система и адаптивные размеры.
- `public/app.js` — навигация, переключатели, фильтры, галерея и составление сообщения.
- `public/assets/` — оригинальные изображения и локальные шрифты.

Цены указаны в KZT. Клиент может предложить свою сумму. Базовые условия: 30/40/30, два раунда правок, 14 дней исправления собственных ошибок. Перед каждым заказом согласуйте точный объём, сроки и условия с клиентом.

Форма не отправляет заявки на сервер и не сохраняет данные. Она собирает проверяемый черновик для Telegram или WhatsApp, который посетитель отправляет сам. Никаких API-ключей не требуется.

Материалы Esports Pulse и оформления ggh_then перенесены из прежнего портфолио. TikTok ведёт в оригинальный профиль. Видеоработы и клиентские отзывы не выдуманы.
